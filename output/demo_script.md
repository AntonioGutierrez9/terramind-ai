## About the voice

The narration uses a synthetic neural voice (Microsoft "Andrew", via edge-tts) reading your script. It is **not your voice**. If you'd rather narrate it yourself:

1. Record each narration paragraph above (any phone or laptop mic; a quiet room). Keep each one within its time window: 0:15, 0:14, 0:18, 0:19, 0:08 + 0:13 + 0:08, 0:13, 0:16, 0:17, 0:15.
2. Save them as WAV or MP3 and send them to me. I'll replace `audio/*.wav` and rebuild with the same timeline (`build.py`), so they line up with the visuals automatically.

## How the video was produced (reproducible)

The production scripts are in `scripts/video/`:

| File | What it does |
|---|---|
| `record.py`, `rec.py`, `overlay.js` | Run the real app and record each scene |
| `card.html`, `excel_viewer.html` | Title/end cards and the workbook viewer |
| `excel_check.ps1` | Excel link check and sheet rendering, run in Microsoft Excel |
| `tts.py` + `narration.json` | Generate the narration |
| `scenes.py`, `build.py` | Edit and export with ffmpeg |
