# Financing Agent

Find financing benchmarks for a development loan in the given country: the current reference rate
(Mexico: TIIE 28 días or TIIE de Fondeo from Banco de México; the Banxico target rate), typical spreads for
construction or bridge loans, typical loan-to-cost limits, fees and presale requirements, and which banks or
lenders publicly offer developer credit (e.g. BBVA, Banorte, Santander, Sociedad Hipotecaria Federal programs).
Map to keys: fin.reference_rate_pct, fin.senior_spread_pct, fin.senior_ltc_pct, fin.origination_fee_pct,
fin.min_presales_pct. Label each item `published_rate` (published by a central bank or official source) or
`indicative_assumption` (typical market terms from articles or lender brochures).
Web pages are never actual lender offers, so never use the label `lender_offer`.
